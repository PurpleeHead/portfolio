# Artem Kutelev — Frontend Portfolio

Personal portfolio website showcasing frontend projects, practical skills, and selected work.

https://purpleehead.github.io/portfolio/

## About

A responsive portfolio built with semantic HTML, CSS, and vanilla JavaScript. It features a bilingual English/Russian interface, light and dark themes, animated interactions, and a curated project list.

## Features

- Responsive project showcase and navigation
- English/Russian language switch
- Light and dark themes with saved preference
- Intersection Observer reveal animations
- Animated hero lens and social links
- Semantic HTML and accessibility-focused details
- Optimized project previews and responsive layouts

## Tech stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Flexbox and CSS Grid
- Responsive design and BEM
- SVG
- Git and GitHub Pages

## Featured projects

### 01. PromptLab — AI Prompt Workspace

A productivity-focused web app for building and maintaining a reusable library of AI prompts. It helps users keep instructions organized, find the right template quickly, personalize prompts with variables, preview the final text, and manage collections and favorites. Built with React, TypeScript, Vite, and SCSS, with local-first data storage, JSON/CSV import and export, and tested core utilities. The project has room to evolve with features such as richer prompt workflows, collaboration, and optional cloud sync.

- [Live demo](https://purpleehead.github.io/PromptLab/)
- [GitHub repository](https://github.com/PurpleeHead/PromptLab)

### 02. Lingvéra — Telegram English Learning Mini App

A deployed Telegram-first learning MVP with a React + TypeScript Mini App, FastAPI backend, PostgreSQL/SQLite persistence, server-side answer validation, progress tracking, and vocabulary review scheduling. The A1 starter course contains 30 lessons and 120 exercises. The Telegram bot provides the `/start` entry point.

- [Open Mini App](https://lingv-ra.pages.dev/)
- [Telegram bot](https://t.me/LingveraLearnBot)
- [GitHub repository](https://github.com/PurpleeHead/Lingv-ra)
- [API health](https://lingv-ra.onrender.com/health)
